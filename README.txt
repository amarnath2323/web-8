TOY WORLD - EXPERIMENT 8: ANGULARJS DIRECTIVES

Files:
- review.html: Add and remove customer reviews using ng-repeat and ng-click.
- bill.html: Calculate addition, subtraction, multiplication and division using ng-model.
- order.html: Add toy names to an order list using ng-repeat and ng-click.

Run:
1. Extract this ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open any HTML file with Live Server.
4. Keep an internet connection so AngularJS CDN can load.

Directives used: ng-app, ng-controller, ng-model, ng-click, ng-repeat and {{ }}.
